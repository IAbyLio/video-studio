# Referentes: cómo usar los vídeos de otros

Biblioteca **tuya** de vídeos ajenos que rindieron (o no), desmontados con la estructura de 8 piezas y el catálogo de ganchos. Sirve para dos cosas: calibrar la nota del crítico y sacar mecanismos reutilizables. Empieza vacía: la IA la llena contigo.

## Regla dura (leer antes de usar cualquier referente)
1. **Se copia el mecanismo, nunca frases, personajes ni cifras ajenas.** De un referente se toma "pasos en orden temporal con una cifra por paso y remate que vuelve al gancho"; no se toma su frase de arranque, ni su personaje, ni sus números. Si una frase de tu guion se reconoce como de un referente, el crítico la marca como obligatorio (veto V2).
2. **Solo se afirma lo que es verdad el día de publicar.** Cada cifra y cada capacidad del guion está en la hoja de hechos y es comprobable ese día.
3. Un referente es n = 1. Las lecciones son hipótesis, no leyes: hay variables que no ves (hora, distribución, momento del tema).

## Cómo desmontar uno (plantilla)
```
### <cuenta o tema> — <fecha de medición>
- Rendimiento: <reproducciones> (≈ <x> veces la mediana de esa cuenta, si la conoces)
- Duración: <s> · Palabras: <n> (≈ <n/s> palabras por segundo)
- Transcripción: (para tu análisis privado; no se copia al guion)

| Pieza | Frase(s) | Qué hace | Cifras / bucles |
|---|---|---|---|
| [1] Gancho | … | tipo del catálogo y por qué frena | |
| … | | | |

Mecanismo reutilizable (en una línea):
Qué NO copiar:
Nota con la rúbrica del crítico (para calibrar): gancho x · claridad x · cifras x · bucles x · ritmo x · CTA x
```

Guarda los desmontajes debajo de esta línea, el más reciente arriba. Transcribir un vídeo propio o ajeno en tu ordenador: `npx hyperframes transcribe video.mp4 --model small --language es --json`.
